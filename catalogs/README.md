# Bundled A2UI Catalogs

This directory contains component catalogs bundled with `a2ui-pane`.

- `v1_0/basic/catalog.json`: A2UI Basic Component Catalog v1.0.
- `v1_0/charts/catalog.json`: A2UI Charts Component Catalog v1.0 (`Chart`).
- `v1_0/status/catalog.json`: A2UI Status Component Catalog v1.0 (`Badge`, `ProgressBar`, `Collapsible`).
- `v0_9_1/basic/catalog.json`: A2UI Basic Component Catalog v0.9.1 (retained for backward compatibility).
