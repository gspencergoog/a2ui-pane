# a2ui-pane

> [!IMPORTANT]
> This repository has moved and is archived. Development continues in the
> A2UI Labs repository at
> [`a2ui-project/labs/plugin/a2ui-pane`](https://github.com/a2ui-project/labs/tree/main/plugin/a2ui-pane).

`a2ui-pane` is a plugin for Antigravity and compatible agent hosts that renders
agent-generated [A2UI](https://a2ui.org/) surfaces in the AuxPane or inline in
chat via `<agent-embed>`. It also ships the `genui` skill that guides when and
how agents use these surfaces.

The code, documentation, installation instructions, and issue tracker now live
in the new location:

- Source: https://github.com/a2ui-project/labs/tree/main/plugin/a2ui-pane
- Issues: https://github.com/a2ui-project/labs/issues

The history in this repository is kept for reference only. No further releases
will be published from here.
